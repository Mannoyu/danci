# h5 学英语单词应用 — 技术设计文档

> 版本：v1.0　|　日期：2026-08-26　|　关联需求：[proposal.md](./proposal.md)

---

## 1. 概述

本文档描述 h5 学英语单词应用（`nextjs-typescript-starter`）的技术实现方案，覆盖数据库表设计、后端 API 与认证、前端页面与组件结构。

**技术栈**：Next.js 14（App Router）+ TypeScript + NextAuth v5（Credentials）+ Drizzle ORM + PostgreSQL（Supabase）+ Tailwind CSS。

**数据源决策**：统一到 Supabase（替换 starter 现有的 `POSTGRES_URL`），`books` / `words` / `users` / `learning_progress` 四张表同库。

## 3. 数据库设计

### 3.1 现有表 `words`（单词）

> 由 `danci-admin` 维护，h5 只读。

```sql
create table public.words (
  id bigint generated by default as identity not null,
  "wordRank" integer null,
  "headWord" text null,
  content json null,
  "bookId" text null,
  constraint words_pkey primary key (id)
) TABLESPACE pg_default;
```

**说明**：
- 列名 `wordRank` / `headWord` / `bookId` 为**驼峰 + 带引号**（历史遗留，PostgreSQL 中需始终加引号引用），Drizzle 映射时列名需与原样一致。
- `content` 为完整单词内容（结构见 proposal §6.1）。
- `bookId` 存放**业务标识**（如 `PEPXiaoXue3_1`），与 `books.book_id` 对应。

**建议补充索引**（性能优化，非必须）：
```sql
create index words_book_id_idx on public.words ("bookId");
create index words_book_id_rank_idx on public.words ("bookId", "wordRank");
```

### 3.2 现有表 `books`（单词书）

> 由 `danci-admin` 维护，h5 只读。

```sql
create table public.books (
  id text not null,
  title text not null,
  word_count integer not null default 0,
  cover_url text null,
  book_id text null,
  created_at timestamp with time zone not null default now(),
  updated_at timestamp with time zone not null default now(),
  tags text null,
  constraint books_pkey primary key (id)
) TABLESPACE pg_default;
```

**关键字段区分**：
- `id`：内部主键（UUID），用于 `learning_progress` 关联。
- `book_id`：业务标识，与 `words.bookId` 对应，用于**按书查词**。

### 3.3 新增表 `users`（用户，认证）

> 承载邮箱密码登录用户，替换 starter 现有的 `User` 表。

```sql
create table public.users (
  id serial primary key,
  email text not null unique,
  password text not null,
  created_at timestamp with time zone not null default now()
);
```

| 列         | 类型      | 说明                                                   |
| ---------- | --------- | ------------------------------------------------------ |
| id         | serial    | 主键，自增                                             |
| email      | text      | 邮箱，唯一                                             |
| password   | text      | bcrypt 哈希（bcrypt 生成固定 60 字符，用 text 留余量） |
| created_at | timestamp | 注册时间                                               |

### 3.4 新增表 `learning_progress`（学习进度）

> 记录每个用户在某本单词书上的学习进度。

```sql
create table public.learning_progress (
  id serial primary key,
  user_id integer not null references public.users(id) on delete cascade,
  book_id text not null references public.books(id) on delete cascade,
  current_word_rank integer not null default 0,
  updated_at timestamp with time zone not null default now(),
  constraint learning_progress_user_book_unique unique (user_id, book_id)
);
```

| 列                | 类型      | 说明                                    |
| ----------------- | --------- | --------------------------------------- |
| id                | serial    | 主键                                    |
| user_id           | integer   | 关联 `users.id`                         |
| book_id           | text      | 关联 `books.id`                         |
| current_word_rank | integer   | 最后学到的 `wordRank`，下次从 `+1` 开始 |
| updated_at        | timestamp | 最近学习时间                            |

**约束与规则**：
- `(user_id, book_id)` 唯一：同一用户对同一本书只有一条进度。
- 「最近学习」= 按 `updated_at` 倒序取第一条。
- 「学习进度」= 每本书 `current_word_rank / books.word_count`。

### 4.2 认证（NextAuth Credentials）

沿用现有 [app/auth.ts](../app/auth.ts) 的 credentials 方案，改造点：

- **数据源**：`getUser` / `createUser` 改为读写 Supabase 的 `users` 表（表名从 `User` 改为 `users`）。
- **session 暴露**：`authorize` 只返回 `{ id, email }`，**不返回 `password`**。
- **登录/注册**：登录调用 `signIn('credentials', ...)`；注册先 `getUser` 查重，再 `createUser`（bcrypt 哈希）。

**关键文件改造**：
- [app/db.ts](../app/db.ts)：连接串改为 Supabase `DATABASE_URL`，表定义对齐 `users`。
- [app/auth.ts](../app/auth.ts)：`authorize` 返回安全字段。
- 新增 `learning_progress` 的读写函数。

### 4.3 Drizzle Schema 定义

```typescript
// app/db/schema.ts
import {
  bigint, integer, json, pgTable, serial, text,
  timestamp, uniqueIndex,
} from "drizzle-orm/pg-core";

// words（已有，驼峰列名需精确匹配）
export const words = pgTable("words", {
  id: bigint("id", { mode: "number" }).generatedByDefaultAsIdentity().primaryKey(),
  wordRank: integer("wordRank"),
  headWord: text("headWord"),
  content: json("content"),
  bookId: text("bookId"),
});

// books（已有）
export const books = pgTable("books", {
  id: text("id").primaryKey(),
  title: text("title").notNull(),
  wordCount: integer("word_count").notNull().default(0),
  coverUrl: text("cover_url"),
  bookId: text("book_id"),
  tags: text("tags"),
  createdAt: timestamp("created_at", { withTimezone: true }).defaultNow().notNull(),
  updatedAt: timestamp("updated_at", { withTimezone: true }).defaultNow().notNull(),
});

// users（新增）
export const users = pgTable("users", {
  id: serial("id").primaryKey(),
  email: text("email").notNull().unique(),
  password: text("password").notNull(),
  createdAt: timestamp("created_at", { withTimezone: true }).defaultNow().notNull(),
});

// learning_progress（新增）
export const learningProgress = pgTable(
  "learning_progress",
  {
    id: serial("id").primaryKey(),
    userId: integer("user_id").notNull().references(() => users.id, { onDelete: "cascade" }),
    bookId: text("book_id").notNull().references(() => books.id, { onDelete: "cascade" }),
    currentWordRank: integer("current_word_rank").notNull().default(0),
    updatedAt: timestamp("updated_at", { withTimezone: true }).defaultNow().notNull(),
  },
  (table) => [
    uniqueIndex("learning_progress_user_book_unique").on(table.userId, table.bookId),
  ],
);
```

### 4.4 API 接口设计

#### 4.4.1 `GET /api/books` — 单词书列表

- 鉴权：无需登录（游客可浏览）。
- 响应：

```json
{
  "books": [
    {
      "id": "uuid",
      "title": "人教版小学英语3下",
      "wordCount": 300,
      "coverUrl": "https://...",
      "bookId": "PEPXiaoXue3_1",
      "tags": "小学,人教版,英语"
    }
  ]
}
```

#### 4.4.2 `GET /api/books/:bookId/words?rank=&limit=` — 某书单词（分页）

- 鉴权：需登录。
- 入参：`rank`（起始 `wordRank`，默认 1）、`limit`（每页数量，默认 20）。
- 通过 `books.book_id` 找到书，再查 `words` 中 `bookId = book_id` 且 `wordRank >= rank`，按 `wordRank` 升序。
- 响应：

```json
{
  "book": { "id": "uuid", "title": "...", "wordCount": 300 },
  "words": [
    {
      "id": 1,
      "wordRank": 1,
      "headWord": "ruler",
      "content": { "word": { "...": "..." } }
    }
  ],
  "nextRank": 21
}
```

#### 4.4.3 `GET /api/words/:wordId` — 单词详情

- 鉴权：需登录。
- 按 `words.id` 查询，返回完整 `content`。

```json
{
  "word": {
    "id": 1,
    "wordRank": 1,
    "headWord": "ruler",
    "bookId": "PEPXiaoXue3_1",
    "content": { "word": { "...": "..." } }
  }
}
```

#### 4.4.4 `GET /api/progress` — 当前用户学习进度

- 鉴权：需登录。
- 返回全部进度（含「最近学习」），关联书名与总词数。

```json
{
  "recent": {
    "book": { "id": "uuid", "title": "...", "coverUrl": "...", "wordCount": 300 },
    "currentWordRank": 25
  },
  "progress": [
    { "book": { "id": "uuid", "title": "..." }, "currentWordRank": 25, "wordCount": 300 }
  ]
}
```

#### 4.4.5 `PUT /api/progress` — 更新进度

- 鉴权：需登录。
- 入参：`{ "bookId": "uuid", "currentWordRank": 26 }`。
- 实现：`upsert`（`ON CONFLICT (user_id, book_id) DO UPDATE`），并刷新 `updated_at`。

## 5. 前端设计

### 5.1 路由与页面

| 路由              | 页面          | 说明                  |
| ----------------- | ------------- | --------------------- |
| `/`               | 首页（Tab 1） | 最近学习 + 全部单词书 |
| `/profile`        | 我的（Tab 2） | 邮箱、学习进度、退出  |
| `/learn/[bookId]` | 单词学习页    | 卡片流，上一个/下一个 |
| `/word/[wordId]`  | 单词详情页    | 完整内容渲染          |

底部 Tab 由 `(main)/layout.tsx` 统一承载，用 `<Link>` 在 `/` 与 `/profile` 间切换（客户端导航，不整页刷新）。

### 5.2 核心组件

| 组件                  | 职责                                                |
| --------------------- | --------------------------------------------------- |
| `tab-bar.tsx`         | 底部固定 Tab，高亮当前项                            |
| `book-card.tsx`       | 单词书卡片（封面/标题/词数），可点击                |
| `recent-learning.tsx` | 最近学习模块（仅登录且有进度时渲染）                |
| `word-card.tsx`       | 极简单词卡片（单词/音标/一个例句/释义），点击进详情 |
| `auth-dialog.tsx`     | 登录/注册 Popup（邮箱 + 密码，登录/注册模式切换）   |
| `progress-bar.tsx`    | 学习进度条                                          |

### 5.3 页面数据获取策略

- **服务端组件（Server Component）**：首页、我的页面用 `auth()` 获取登录态，`db` 直查数据，SSR 输出。
- **客户端组件（Client Component）**：登录 Popup、单词学习页的翻卡交互用 `'use client'`。
- **单词学习页**：进入时按当前进度 `rank` 拉取一页单词（如 20 个），页内切换；到页边界再拉取上一页/下一页。

### 5.4 数据流

```
首页(Server) ──auth()──▶ 登录态
     │
     ├─ 已登录 ──db 查 learning_progress──▶ 「最近学习」模块
     └─ 查 books ─▶ 全部单词书列表

点击单词书
  ├─ 未登录 ─▶ 跳「我的」+ 弹 auth-dialog
  │             └─ signIn/createUser ─▶ 回到该书学习页
  └─ 已登录 ─▶ /learn/[bookId] ─▶ GET /api/books/:id/words

学习页翻卡
  └─ 切换下一个 ─▶ PUT /api/progress (currentWordRank) ─▶ 刷新「最近学习」
```

## 6. 关键实现要点

1. **列名映射**：`words` 表驼峰列名（`wordRank`/`headWord`/`bookId`）在 Drizzle 中列名参数必须原样带引号，否则查询报列不存在。
2. **书的两套 ID**：`books.id`（UUID，进度关联）与 `books.book_id`（业务标识，查词关联）需严格区分，避免混用。
3. **进度 upsert**：更新学习进度用 `ON CONFLICT (user_id, book_id)` 实现幂等，避免重复插入。
4. **续学定位**：`currentWordRank + 1` 作为起始 `rank` 进入学习页。
5. **认证改造**：`authorize` 不得返回 `password`；`users` 表替换原 `User` 表名。
6. **数据源切换**：`app/db.ts` 的 `postgres()` 连接串从 `POSTGRES_URL` 改为 Supabase `DATABASE_URL`。

---

## 7. 安全与性能

- **安全**：密码 bcrypt 哈希；`/api/books/:id/words`、`/api/words/:id`、`/api/progress` 均需登录鉴权；`authorize` 不暴露密码。
- **性能**：单词列表分页（默认 20/页）；`words` 表建议加 `("bookId", "wordRank")` 复合索引以加速按书内顺序查询。
- **体验**：翻卡更新进度可做防抖，避免频繁写库；加载/空态/错误态均有反馈。
