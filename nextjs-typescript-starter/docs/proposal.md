# h5 学英语单词应用 — 需求文档

> 版本：v1.0　|　日期：2026-08-26　|　状态：待评审

---

## 1. 背景与目标

### 1.1 背景
已有 `danci` 单词书后台管理系统（`danci-admin`），负责单词书（`books`）与单词（`words`）数据的录入、清洗与管理。数据存储在 Supabase（PostgreSQL）中。

现需要面向**移动端用户**（h5）提供一个学习侧应用，让用户：
- 浏览单词书
- 以卡片形式学习单词
- 查看单词详情
- 记录并继续学习进度

### 1.2 目标
1. 提供一个移动端（h5）友好的学习界面。
2. 复用已有登录/注册能力（NextAuth credentials），实现邮箱密码登录与注册。
3. 复用已有 `books` / `words` 数据。
4. 新增「学习进度」能力，支持「最近学习」续学与进度展示。

### 1.3 非目标（本期不做）
- 单词发音音频的云端托管与播放（仅预留字段）。
- 复杂的记忆曲线 / 艾宾浩斯复习算法。
- 单词搜索、收藏、生词本。
- 后台管理能力（由 `danci-admin` 负责）。

---

## 2. 用户与场景

- **游客**：未登录，可浏览单词书列表，但不能进入学习。
- **注册用户**：登录后可学习单词、查看/续接学习进度。

核心场景：
1. 游客浏览单词书 → 点击某本书 → 被引导登录 → 登录后进入学习。
2. 已登录用户打开首页 → 看到「最近学习」→ 点击「继续学习」→ 从上次进度下一个单词开始。
3. 用户逐张翻看单词卡片 → 点击单词进入详情页查看完整释义、例句、同近义词、记忆法。
4. 用户在「我的」页面查看邮箱、学习进度、退出登录。

## 4. 数据模型

### 4.1 现有表（数据来源，由 danci-admin 维护）

#### `words` 表（单词）
| 列       | 类型    | 说明                      |
| -------- | ------- | ------------------------- |
| id       | bigint  | 主键，自增                |
| wordRank | integer | 单词在书中的序号          |
| headWord | text    | 词头（如 `ruler`）        |
| content  | json    | 单词完整内容（结构见 §6） |
| bookId   | text    | 所属单词书 bookId         |

#### `books` 表（单词书）
| 列                    | 类型      | 说明                         |
| --------------------- | --------- | ---------------------------- |
| id                    | text      | 主键（UUID）                 |
| title                 | text      | 书名                         |
| wordCount             | integer   | 单词总数                     |
| coverUrl              | text      | 封面图 URL                   |
| bookId                | text      | 关联 `words.bookId` 的书标识 |
| tags                  | text      | 标签（逗号分隔）             |
| createdAt / updatedAt | timestamp | 时间戳                       |

### 4.2 现有表（用户认证）

#### `User` 表
| 列       | 类型        | 说明        |
| -------- | ----------- | ----------- |
| id       | serial      | 主键        |
| email    | varchar(64) | 邮箱        |
| password | varchar(64) | bcrypt 哈希 |

### 4.3 新增表（本期需要）

#### `learning_progress` 表（学习进度）
用于记录每个用户在某本单词书上的学习进度。

| 列              | 类型      | 说明                                        |
| --------------- | --------- | ------------------------------------------- |
| id              | serial    | 主键                                        |
| userId          | integer   | 关联 `User.id`                              |
| bookId          | text      | 关联 `books.id`（或 `books.bookId`）        |
| currentWordRank | integer   | 最后学到的单词 `wordRank`，下次从 `+1` 开始 |
| updatedAt       | timestamp | 最近学习时间                                |

约束与规则：
- `(userId, bookId)` 唯一，同一用户对同一本书只有一条进度记录。
- 「最近学习」= 按 `updatedAt` 倒序取第一条。
- 「学习进度」= 每本书 `currentWordRank / wordCount`。

> **决策（已确认）**：数据源统一到 Supabase。h5 直接连接 Supabase 的 `books` / `words` 表，`User` / `learning_progress` 也一并放在同一库（替换 starter 当前的 `POSTGRES_URL`），便于关联查询。

## 5. 页面与功能需求

### 5.1 全局布局：底部 Tab

应用整体为移动端单页结构，底部固定两个 Tab：

- **首页**：单词书浏览 + 最近学习。
- **我的**：账号信息 + 学习进度 + 退出登录。

要求：
- 底部 Tab 固定，内容区可滚动。
- 切换 Tab 不整页刷新，保持流畅。
- 登录状态通过 NextAuth session 判断（服务端 `auth()`）。

### 5.2 首页（Tab 1）

#### 5.2.1 已登录状态
按顺序展示：
1. **「最近学习」模块**：仅当存在学习进度时展示；否则不渲染该模块。
   - 展示：单词书封面、书名、已学进度（如 `已学 25 / 300`）、「继续学习」按钮。
   - 点击 → 进入该书的「单词学习页」，从 `currentWordRank + 1` 的单词开始。
2. **「全部单词书」列表**：展示所有单词书。
   - 每项展示：封面、书名、单词数量。
   - 点击 → 进入该书「单词学习页」（从第一个单词开始，或从已有进度继续）。

#### 5.2.2 未登录状态
- 只展示「全部单词书」列表（不展示「最近学习」）。
- 点击任意单词书 → **跳转到「我的」Tab 并弹出登录 Popup**（见 §5.5）。
- 登录/注册成功后，**自动返回并进入刚才点击的那本书**（需记住点击意图，登录完成后跳转到对应学习页）。

### 5.3 我的页面（Tab 2）

展示：
1. **用户邮箱**（`session.user.email`）。
2. **学习进度**：列出有进度的单词书，每项含书名 + 进度条 + 百分比。
   - 无进度时展示空态提示（如「暂无学习记录」）。
3. **退出登录**：调用 `signOut()` 退出。

### 5.4 单词学习页（卡片流）

用户点击单词书或「继续学习」后进入。

- 顶部：返回按钮 + 书名 + 当前位置（`3 / 300`）。
- 中间：单词卡片（**极简**，见 §6 字段选择）。
- 底部：`上一个` / `下一个` 切换按钮。
- 每切换到一个新单词，更新 `learning_progress`（`currentWordRank` 与 `updatedAt`）。
- 点击卡片主体（单词区域）→ 进入「单词详情页」。

### 5.5 登录 / 注册 Popup

在「我的」页面以 Popup（弹层）形式承载登录与注册，复用现有邮箱 + 密码逻辑。

- 两种模式：登录 / 注册（可 Tab 切换，或「没有账号？去注册」链接切换）。
- 字段：邮箱、密码。
- 登录：调用 NextAuth `signIn('credentials', ...)`。
- 注册：先查 `getUser` 判断邮箱是否已存在，不存在则 `createUser`，再引导登录。
- 校验失败时给出友好提示（如「邮箱已注册」「密码错误」）。

> 复用点：现有 [app/login/page.tsx](../app/login/page.tsx) 的 `signIn` 逻辑、[app/register/page.tsx](../app/register/page.tsx) 的 `createUser` 逻辑、[app/form.tsx](../app/form.tsx) 的邮箱/密码表单结构。

### 5.6 单词详情页

点击单词卡片后进入，渲染**完整单词内容**（`content.word.content`）。

展示区块（按顺序）：
1. 单词 + 音标（英/美）。
2. 中文释义 + 英文释义。
3. 例句列表（英文 + 中文）。
4. 同近义词。
5. 同根词。
6. 记忆法。

## 6. 单词 JSON 结构与字段选择

### 6.1 完整数据结构

```json
{
  "wordRank": 1,
  "headWord": "ruler",
  "content": {
    "word": {
      "wordHead": "ruler",
      "wordId": "PEPXiaoXue3_1_1",
      "content": {
        "sentence": {
          "sentences": [{ "sContent": "a 12-inch ruler", "sCn": "一把12英寸的尺子" }],
          "desc": "例句"
        },
        "usphone": "'rulɚ",
        "syno": {
          "synos": [{ "pos": "n", "tran": "...", "hwds": [{ "w": "governor" }, { "w": "dominator" }] }],
          "desc": "同近"
        },
        "ukphone": "'ruːlə",
        "ukspeech": "ruler&type=1",
        "relWord": { "desc": "同根", "rels": [ { "pos": "adj", "words": [ { "hwd": "ruling", "tran": "..." } ] } ] },
        "remMethod": { "val": "没有规矩(rule)，不成方圆，尺子(ruler)可以用来规划图形", "desc": "记忆" },
        "usspeech": "ruler&type=2",
        "trans": [
          {
            "tranCn": "尺子",
            "descOther": "英释",
            "descCn": "中释",
            "tranOther": "a long flat straight piece of plastic, metal, or wood..."
          }
        ]
      }
    }
  },
  "bookId": "PEPXiaoXue3_1"
}
```

### 6.2 单词卡片（学习页）—— 极简，只展示一个示例

| 展示内容           | 来源字段                                              |
| ------------------ | ----------------------------------------------------- |
| 单词               | `headWord`                                            |
| 音标（美式，可选） | `content.word.content.usphone`                        |
| 一条例句（英文）   | `content.word.content.sentence.sentences[0].sContent` |
| 一条例句（中文）   | `content.word.content.sentence.sentences[0].sCn`      |
| 中文释义           | `content.word.content.trans[0].tranCn`                |

### 6.3 单词详情页 —— 完整渲染 `content.word.content`

| 区块         | 来源字段                                                                        |
| ------------ | ------------------------------------------------------------------------------- |
| 单词         | `content.word.wordHead`                                                         |
| 英/美音标    | `content.word.content.ukphone` / `usphone`                                      |
| 发音（预留） | `content.word.content.ukspeech` / `usspeech`                                    |
| 释义         | `content.word.content.trans[]`（`tranCn` 中释 / `tranOther` 英释）              |
| 例句         | `content.word.content.sentence.sentences[]`（`sContent` / `sCn`）               |
| 同近义词     | `content.word.content.syno.synos[]`（`pos` / `tran` / `hwds[].w`）              |
| 同根词       | `content.word.content.relWord.rels[]`（`pos` / `words[].hwd` / `words[].tran`） |
| 记忆法       | `content.word.content.remMethod.val`                                            |

## 8. API 设计（建议）

| 方法 | 路径                   | 说明                                   |
| ---- | ---------------------- | -------------------------------------- |
| GET  | `/api/books`           | 单词书列表                             |
| GET  | `/api/books/:id/words` | 某本书的单词列表                       |
| GET  | `/api/words/:id`       | 单词详情                               |
| GET  | `/api/progress`        | 当前用户全部学习进度（含「最近学习」） |
| PUT  | `/api/progress`        | 更新某本书的 `currentWordRank`         |

> 认证接口沿用 NextAuth：`/api/auth/[...nextauth]`。

## 9. 交互流程

### 9.1 游客 → 学习
```
浏览首页单词书 → 点击某本书
  → 未登录 → 跳转「我的」Tab + 弹出登录 Popup
  → 登录/注册成功 → 返回并进入该书学习页
```

### 9.2 续学
```
首页「最近学习」→ 点击「继续学习」
  → 进入学习页，定位到 currentWordRank + 1
```

### 9.3 学习进度更新
```
学习页切换「下一个」→ 当前 wordRank 写入 learning_progress
  → updatedAt 刷新 → 该记录成为新的「最近学习」
```

## 10. 非功能性需求

- **移动优先**：布局适配主流手机屏幕（375px ~ 430px 宽），触摸目标 ≥ 44px。
- **性能**：单词列表分页/懒加载（单本书单词量较大，避免一次全量拉取）。
- **状态反馈**：加载中、空态、错误态均有明确提示。
- **安全**：密码 bcrypt 哈希（沿用）；学习进度接口需登录鉴权。

## 11. 验收标准

- [ ] 底部「首页 / 我的」Tab 可正常切换。
- [ ] 已登录首页展示「最近学习」；无进度时不展示该模块。
- [ ] 未登录点击单词书会跳转「我的」并弹出登录 Popup。
- [ ] 邮箱 + 密码可完成登录与注册。
- [ ] 「我的」页面展示邮箱、学习进度、退出登录。
- [ ] 单词学习页以极简卡片展示（单词 + 一个例句 + 释义），可「上一个/下一个」切换。
- [ ] 学习进度随翻卡实时更新，「最近学习」可续学。
- [ ] 点击单词进入详情页，完整展示音标、释义、例句、同近义词、同根词、记忆法。
